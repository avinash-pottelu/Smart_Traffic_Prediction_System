# 🚦 Smart Traffic Prediction Analytics Dashboard

## 📌 Project Overview
Smart Traffic Prediction Analytics Dashboard is a real-world Data Analytics project built using SQL, Python, and Tableau.

The main goal of this project is to analyze:
- traffic congestion
- peak traffic hours
- accident hotspots
- weather impact on traffic
- travel time trends
- vehicle movement patterns

This project simulates how smart city traffic analytics systems work in real-world environments.
